# Plan: 3008 no es 2008

Implementado. El typo de letras (Hilus, Dimax) sigue en el léxico. Un número de modelo no se acerca a otro, y `3008n` de ficha es la línea 3008. Lo mal escrito que no calza exacto lo lee el embedding / el agente.

## Qué se borra

El fuzzy que trata `3008` como `2008` (una cifra, misma longitud). Un número de modelo no se acerca a otro número.

La familia `3008n` como si fuera otra línea. En patio el token trae una letra de ficha; el cliente dice `3008`.

## Qué no se borra

Sportage, Hilux, D-Max, “Peugeot 2008 es modelo no año”, `208` vs `2008`. Eso no es distancia entre 3008 y 2008.

El embedding no ataba el UUID. Si el nombre ya calza, no hace falta embeber. Si no calza, el embedding sigue, pero ya no filtra con familia `2008` cuando el cliente dijo `3008`.

## Cómo queda

| Dijo | Patio | Qué pasa |
|---|---|---|
| Peugeot 3008 | 3008n y 2008 | Se ata el 3008n. Fotos de esa unidad |
| Peugeot 2008 | 2008 | Sigue el 2008 |
| Peugeot 208 | no hay 208 | No se convierte en 2008. “No tenemos” si no está |

Ficha y `inventory_id` salen de la misma unidad.
